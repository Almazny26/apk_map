## Как всё устроено

```
web/index.html (приложение товарища, Leaflet) + net.js (карта сети) + exchange.js (обмен файлами)
   ├─ телефон: android/ — WebView, страница из assets, мосты AndroidBridge и KartaFiles
   └─ компьютер: run.py (127.0.0.1) подставляет pc.js (в начало) и pc-ui.js (в конец), окно Edge/Chrome --app
```

- **`web/`** — ассеты из APK товарища без изменений: `index.html`, `leaflet/`, `tiles/` (плитки
  OSM зум 7–11, 1562 файла), `dem/dem.bin` (рельеф). В `index.html` изменены ровно три вещи:
  `<title>Карта сети</title>` и `<script src="net.js">`, `<script src="exchange.js">` перед `</body>`. Проверять
  diff'ом с оригиналом (`/home/claude/apkx/fresnel/x/assets/`, если песочница жива, иначе из APK).
- **Данные приложения** (localStorage): `wf_session` (точки, частота, лес, высота, модель),
  `wf_nodes` (паспорт ВОЛС), `wf_hist` (до 25 профилей), `wf_theme`, `wf_online`, `wf_tool`.
- **`web/exchange.js`** — кнопка «Файл» в шапке и окно в стиле его окна «История». Файл:
  `{format: "karta-seti", kind: "fresnel", version: 1, app, created, source, data: {session,
  nodes, hist}}`. Импорт заменяет `session` и `nodes`, историю объединяет (без повторов, не больше
  25), перезагружает страницу. Прежнее состояние кладётся в `karta_prev` («Вернуть как было»).
  На Android — `KartaFiles.shareText/saveText/openFile`, на ПК — скачивание и `<input type=file>`.
- **`web/net.js`** — постоянная карта сети. `karta_net = {v, objs: {id: {id, type: node|radio|fiber,
  f: поля, ft: время правки каждого поля, t, by}}, journal}`. Вкладка «Сеть» (#panelNet): узлы
  (название, вид, состояние работает/авария/работы/план, адрес, примечание), список с поиском и
  фильтром, журнал, подпись изменений (`karta_author`). Слой сети на карте во всех вкладках,
  карточка по нажатию (Изменить, Точка A/B, Открыть, Удалить). «Сохранить в сеть» в панелях
  «Радио» и «ВОЛС»; открытая в редакторе линия — `karta_cur {radio, fiber}`, она скрыта в слое
  сети, пока открыта. Перехваты функций приложения (они глобальные, поэтому подмена через window
  работает): `place`, `addNode` — прилипание к узлу сети в 22 px; `redrawMap`, `drawNodes` —
  перетаскивание точек и «+» между точками паспорта (вставка опоры); `setTool`; `calc` — запоминает,
  для каких точек посчитан профиль (результат сохраняется с линией). «Где я»: на телефоне
  `KartaFiles.locate()` → `window.__kartaGeo`, на ПК — `navigator.geolocation`.
  Своих окон `confirm/prompt` нет (в WebView без WebChromeClient они не работают) — окно #netDlg.
  `window.KartaNet` — для exchange.js: `data`, `counts`, `preview`, `merge`.
- **`web/pc-ui.js`** — только для ПК, в конце страницы: панели приложения в окнах поверх карты
  (перетаскивание, растягивание за края, свернуть, развернуть, раскладка в `karta_pc_layout`),
  окно профиля (подмена `setupCanvas`/`draw`: размер по окну, dpr 1, крупные подписи), история,
  обмен и #netDlg — окна без затемнения, окно текста вместо mailto, строка состояния с
  координатами и СК-42, Esc.
- **`web/pc.js`** — только для ПК, вставляется сервером после `leaflet.js`: localStorage
  (ключи `wf_*`, `karta_*`) синхронно сохраняется в `data/state.json`; плитки `https://local.tiles/`
  → `/tiles/`; онлайн-плитки блокируются без галочки «Онлайн»; заменитель `AndroidBridge`
  (`fetchElevations` → `/api/elev`, `saveImage` → скачивание PNG).
- **`run.py`** (2.0) — только стандартная библиотека. Слушает 127.0.0.1:8790, отказывает чужим
  `Host`/`Origin`. `/api/state` GET/POST, `/api/elev` (тот же алгоритм DEM, что у товарища; при
  «Онлайн» добирает высоты в open-meteo), `/api/info`. Плитки — из `web/tiles/` или `web/tiles.zip`.
  Резервные копии `data/backups/state-ГГГГ-ММ-ДД.json`, 30 штук. Повторный запуск только открывает окно.
- **`android/`** — пакет `ru.netmap.app` (наш, ставится поверх «Карты сети»). `MainActivity.java`
  — перенос оболочки товарища один в один (восстановлена androguard'ом): те же настройки WebView,
  перехват `local.tiles`, блокировка сети вне «Онлайн», класс DEM, мост `AndroidBridge`
  (`fetchElevations`, `saveImage`, `setOnline`). Добавлен мост `KartaFiles` и приём файлов
  (`VIEW`, `SEND`), `ShareProvider` для «Поделиться». Значок — наш (адаптивный + PNG).
- **Сборка APK** — GitHub Actions, `.github/workflows/build-apk.yml`, `assets.srcDirs ['../../web']`.
  Кладёт `apk/karta-seti.apk` и `apk/version.json` отдельным коммитом. versionCode = номер запуска.

### Формат dem.bin

`"DE"` + 2 байта, `uint16` число квадратов; квадрат: `int16` широта, `int16` долгота, `uint16 n`,
затем `n×n` `int16` (little-endian), строки с севера. Билинейно: `r = (lat0 + 1 − lat)·(n − 1)`,
`c = (lon − lon0)·(n − 1)`.

## Принятые решения и почему

- **Страница товарища не трогается.** Всё новое — в отдельных файлах (`exchange.js`, `pc.js`),
  чтобы его обновления можно было переносить простой заменой `index.html` (и вернуть две строки).
- **ПК-версия — та же страница**, а не переписанная: сервер подставляет `pc.js`, который заменяет
  мост Android. Данные — в файле на диске, а не в localStorage браузера, чтобы не пропадали при
  чистке браузера и попадали в резервные копии.
- **Сервер только на 127.0.0.1**, проверка `Host`/`Origin` от чужих страниц в браузере.
- **Сеть при импорте объединяется** (для каждого поля — более поздняя правка, удаление — поле
  `deleted`), повторная загрузка файла ничего не меняет. **Текущая работа** (точки радиолинии и
  паспорт) заменяется только с флажком; флажок включён, если в файле нет сети (старые файлы).
  История профилей дополняется. Ошибочная загрузка отменяется «Вернуть как было» (снимок и сети).
- **Доработки — отдельными файлами** (`net.js` и др.), приложение товарища меняется минимально:
  его функции подменяются через `window`, его панели дополняются через DOM.
- **На рабочий стол плитки идут архивом `web/tiles.zip`**: передача на ПК ограничена 50 файлами за
  раз. `run.py` читает и папку, и архив. `*.zip` в `.gitignore`.
- **Ключ подписи APK** в репозиторий не кладётся (репозиторий публичный). Сборка берёт его из
  секрета GitHub `KEYSTORE_B64` (PKCS12, псевдоним `netmap`, пароль в `android/app/build.gradle`).
  Копия у заказчика: `Desktop\Карта сети\data\ключ подписи APK\`. Потерять нельзя. Первый ключ
  (до 12.11.2026) остался в истории репозитория и считается раскрытым.
- **targetSdk 34**, а не 35: с 35 Android рисует приложение под системными панелями.

- Программы поставляются папкой на рабочем столе, не архивом. Папка проекта: `Desktop\Карта сети`.

  В репозиторий кладётся вариант, который попал на рабочий стол.
- Файлы в `.github/` Claude в папку на рабочем столе положить не может, их восстанавливает
  bat-файл через `git checkout -- .github`.
- Удалять файлы на компьютере заказчика Claude не может без разрешения — лишнее перечисляется ему.
