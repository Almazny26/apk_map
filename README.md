# Карта сети

С версии 2.0 основа программы — приложение товарища **«WiFi Френель»** (1.24): расчёт радиолиний
по рельефу и паспорт линии ВОЛС. Его приложение не переделывалось, к нему добавлено:

- **обмен файлами** — кнопка «Файл» в шапке: сохранить данные в файл, открыть файл с другого
  телефона или компьютера, «Вернуть как было» после загрузки;
- **программа для компьютера** — то же приложение в отдельном окне, данные хранятся в папке `data`;
- название «Карта сети» и наш значок; приложение ставится поверх прежней «Карты сети».

Прежняя версия (1.3, своя карта узлов и линий) сохранена в GitHub в ветке `v1.3-karta-seti`.

## Что умеет (от товарища)

- Радиолиния: точки A, B и промежуточные, высоты мачт, частота, лес и застройка; профиль рельефа,
  зоны Френеля, сколько поднять мачты, юстировка (азимуты), подбор оборудования, бюджет канала,
  картинка профиля (PNG), история профилей.
- ВОЛС: паспорт линии — опоры, муфты, узлы, кроссы, расстояния, координаты СК-42, расчёт кабеля.
- Карта (с версии 2.3): «Схема» — подробная карта OpenStreetMap из интернета на любом масштабе,
  «Спутник», «Гибрид». Всё, что открывали с интернетом, сохраняется и видно без связи (до 500 МБ на
  телефоне, до 1 ГБ на компьютере). Без интернета и вне просмотренного — вшитая карта Крыма,
  Херсонской и Запорожской областей, Ставрополья. Рельеф SRTM на те же районы, с «Онлайн» — везде.
  Без галочки «Онлайн-карты и высоты» приложение в интернет не ходит.
- На телефоне меню — шторка снизу: тянуть за ручку вверх и вниз, смахнуть вниз по списку; пока
  ставится точка, шторка уходит вниз.

## Карта сети (добавлено к приложению товарища)

- Вкладка **«Сеть»**: узлы доступа (название, вид, состояние, адрес, примечание) и сохранённые
  линии. Поиск, фильтр (узлы, радиолинии, ВОЛС, аварии, работы, план), журнал «кто и когда».
- Сеть видна на карте во всех вкладках. Нажатие на узел или линию — карточка: изменить, удалить,
  открыть линию для правки, поставить точку A или B радиолинии на узел.
- **Соединить узлы** — в карточке узла (нажать на узел):
  - «ВОЛС до узла» → нажать второй узел: линия появится по прямой; чтобы провести её по улицам,
    тяните точки и «+» между ними (вставка опоры);
  - «ВОЛС по точкам» → нажимайте по трассе (каждое нажатие — опора), нажмите на узел — линия
    закончится; внизу «Назад» (убрать точку) и «Готово»;
  - «Радиолиния до узла» → второй узел: профиль посчитается сам.
  Линия ВОЛС сохраняется сама и называется по узлам («УД-1 — УД-2»). Передвинули узел — концы
  линий едут за ним. Во вкладке «ВОЛС»: «Новая линия» и «Ставить точки».
- Во вкладке «Радио» — **«Сохранить в сеть»**. Открытую линию можно править и сохранить
  изменения или сохранить как новую.
- Точки радиолинии и паспорта **перетаскиваются**, между точками паспорта есть «+» — вставить опору.
  Точка, поставленная рядом с узлом сети, встаёт точно на узел.
- **Вся схема:** кнопка ⤢ на карте (и «Вся сеть» во вкладке «Сеть») показывает все узлы и линии
  сразу. Линии подписаны названиями. Работа соседней вкладки тоже видна (бледнее). Если нажать
  «Очистить» у несохранённой линии, программа предложит сначала сохранить её в сеть.
- **«Где я»** (кнопка ◉ на карте): точка по GPS телефона, из неё — узел, точка радиолинии или
  паспорта.

## Обмен файлами

1. Кнопка **«Файл»** → «Поделиться файлом» (телефон) или «Сохранить в файл».
2. Файл (`karta-seti-ДАТА.json`) пересылается в мессенджере или переносится как угодно.
3. На другом устройстве: «Файл» → «Открыть файл», или на телефоне нажать на файл в мессенджере →
   «Открыть с помощью» → «Карта сети».
4. Программа покажет, что в файле, и спросит подтверждение. **Сеть объединяется**: новые узлы и
   линии добавляются, изменённые обновляются (если одно и то же поменяли двое — остаётся более
   поздняя правка), повторная загрузка того же файла ничего не меняет. Текущая работа (точки
   радиолинии и паспорт) заменяется, только если отметить флажок. Если загрузили не то —
   «Файл» → «Вернуть как было».

## Что в папке

| Что | Зачем |
|---|---|
| `Карта сети.bat` | запуск программы на компьютере (отдельное окно) |
| `GitHub - подключить и обновить.bat` | связать папку с репозиторием и получать обновления |
| `apk/karta-seti.apk` | приложение для телефона |
| `run.py` | программа для компьютера (Python 3.8+, без дополнительных пакетов) |
| `web/` | приложение товарища (`index.html`, карта, рельеф) и наши `exchange.js`, `pc.js` |
| `web/tiles.zip` | карта без интернета для компьютера (в GitHub лежит папкой `web/tiles`) |
| `android/` | оболочка приложения для телефона |
| `data/` | данные этого компьютера и резервные копии (в GitHub не попадает) |

## Компьютер

Нужен Python 3.8 или новее. Запустите `Карта сети.bat` — откроется окно программы. Панели —
окна поверх карты: перетаскиваются за заголовок, растягиваются за края, сворачиваются,
разворачиваются двойным щелчком; «Окна по умолчанию» внизу справа возвращает их на места. Чёрное окно не
закрывайте, пока работаете. Программа доступна только с этого компьютера, по сети к ней
подключиться нельзя. Данные — в `data\state.json`, копия за каждый день — в `data\backups`
(хранятся 30 последних).

## Телефон

Установите `apk\karta-seti.apk`. Новая версия ставится поверх старой.

## Для разработки

- Проверка: `python -m unittest discover -s tests -v`.
- APK собирает GitHub Actions при изменениях в `web/` или `android/`.
- Подробности и история решений — в `CLAUDE.md`.
