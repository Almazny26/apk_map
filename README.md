# Карта сети

Карта узлов и линий транспортной сети связи: приложение для телефона (Android) и программа для
компьютера (Windows). Основа — приложение товарища **«WiFi Френель»** (карта на Leaflet, вшитая
карта и рельеф); с версии 3.0 расчёты радиолиний и паспорт ВОЛС убраны — у линии остаётся
протяжённость.

Прежние версии: 1.3 (своя карта, сервер) — ветка `v1.3-karta-seti`; 2.x — история репозитория.

## Два режима

Сверху — **«Просмотр»** и **«Редактирование»**. При запуске всегда «Просмотр»: ничего нельзя
сдвинуть, нажатие на узел или линию показывает сведения (протяжённость, по опорам / в земле,
откуда и куда, все точки с координатами СК-42).

В «Редактировании»:

- кнопка **«+»** справа внизу — узел, линия ВОЛС, радиолиния;
- точки ставятся **в перекрестие**: двигайте карту и нажимайте «Поставить точку» — или просто
  нажмите на нужное место. Перекрестие на узле зеленеет — линия закончится на нём;
- у линии ВОЛС для каждого участка указывается прокладка: **по опорам** (сплошная оранжевая) или
  **в земле** (коричневый пунктир); одна линия может идти сначала по столбам, потом под землёй.
  Вид точки — опора, колодец, муфта, кросс, точка;
- нажмите на линию — у неё появятся точки: тяните их, «+» между точками добавляет новую;
  узел тоже можно перетащить, концы линий едут за ним;
- **долгое нажатие** (на компьютере — правая кнопка):
  на точку — вид, номер, прокладка соседних участков, удалить;
  на линию — вставить точку здесь, прокладка этого участка, продолжить, название, удалить;
  на узел — изменить, линия ВОЛС или радиолиния отсюда, переместить, удалить.

На телефоне сведения открываются внизу свёрнутыми (название и длина) — нажмите, чтобы развернуть.
Смахивание вниз сворачивает и прячет карточку, но линия остаётся выделенной и её можно править;
выделение снимает «×» или нажатие на пустое место карты.

Справа сверху — поиск и список (🔍) и меню «⋮»: обмен данными, журнал изменений, карта без
интернета, карта из интернета, тёмная тема, подпись изменений.

## Карта без интернета

Карта из интернета (OpenStreetMap, снимки Esri) хранит всё, что уже открывали. А для работы без
связи есть **офлайн-карта районов** — файл `map\karta-offline.pmtiles`: улицы, дома, дороги,
названия по-русски, масштаб до самого крупного. Сейчас в нём **Херсонская и Запорожская
области** (около 190 МБ).

- Компьютер: файл лежит в папке программы `map\`, программа берёт его сама. Обновить или
  добавить районы (Крым, Ставропольский край): «⋮» → «Карта без интернета» (нужен интернет).
- Телефон: перешлите файл `karta-offline.pmtiles` на телефон (кабель, мессенджер) и выберите его в
  «⋮» → «Карта без интернета» (или нажмите на файл → «Открыть с помощью» → «Карта сети»).

Данные — © участники OpenStreetMap (лицензия ODbL, сборка Protomaps). Снимки без интернета
видны только там, где их уже открывали.

## Обмен файлами

1. «⋮» → «Обмен данными» → «Поделиться файлом» (телефон) или «Сохранить в файл».
2. Файл `karta-seti-ДАТА.json` пересылается в мессенджере или переносится как угодно.
3. На другом устройстве: «Обмен данными» → «Открыть файл…», или на телефоне нажать на файл в
   мессенджере → «Открыть с помощью» → «Карта сети».
4. Программа покажет **список изменений**: что добавится, что изменится (и какие поля), что
   удалится. После «Загрузить» карта становится **точно как в файле** — старых точек не
   остаётся. Прежняя карта сохраняется: «Обмен данными» → «Вернуть карту, какой она была».

## Что в папке

| Что | Зачем |
|---|---|
| `Карта сети.bat` | запуск программы на компьютере (отдельное окно) |
| `GitHub - подключить и обновить.bat` | связать папку с репозиторием и получать обновления |
| `apk/karta-seti.apk` | приложение для телефона |
| `run.py` | программа для компьютера (Python 3.8+, без дополнительных пакетов) |
| `map/karta-offline.pmtiles` | офлайн-карта районов (в GitHub не лежит — большой файл) |
| `web/` | страница приложения: `index.html` (товарища), `app.js` (интерфейс и карта сети), `maps.js` (подложки), `pc.js` (компьютер), `vendor/` |
| `web/tiles.zip` | общая карта без интернета до масштаба 11 (в GitHub лежит папкой `web/tiles`) |
| `android/` | оболочка приложения для телефона |
| `data/` | данные этого компьютера и резервные копии (в GitHub не попадает) |

## Компьютер

Нужен Python 3.8 или новее. Запустите `Карта сети.bat` — откроется окно программы. Сведения и
меню — в панели слева, справа внизу — масштаб, «вся сеть», «где я», внизу — координаты и СК-42
под курсором. Чёрное окно не закрывайте, пока работаете. Программа доступна только с этого
компьютера, по сети к ней подключиться нельзя. Данные — в `data\state.json`, копия за каждый
день — в `data\backups` (хранятся 30 последних).

## Телефон

Установите `apk\karta-seti.apk`. Новая версия ставится поверх старой, данные сохраняются.

## Для разработки

- Проверка: `python -m unittest discover -s tests -v`.
- Офлайн-карта без окна: `python run.py --offline-map "Херсонская область" "Запорожская область"`.
- APK собирает GitHub Actions при изменениях в `web/` или `android/`.
- Подробности и история решений — в `CLAUDE.md`.
