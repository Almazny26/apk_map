# Карта сети

Карта узлов доступа транспортной сети и линий между ними. С версии 1.3 — **без работы по сети**:

- **Программа на компьютере** у диспетчера: общая, «главная» карта. Работает только на этом
  компьютере, по сети к ней подключиться нельзя.
- **Приложение на телефоне** у каждой бригады: работает без интернета и без сервера.

Обмен идёт файлами:

1. Утром диспетчер выгружает **файл карты** (меню → «Выгрузить карту для бригад») и пересылает его бригадам.
2. Бригада открывает файл на телефоне (нажать на файл в мессенджере → «Открыть с помощью» → «Карта сети»).
3. На выезде бригада ставит узлы, проводит линии, меняет состояния, пишет примечания.
4. Бригада отправляет диспетчеру **файл изменений** (меню → «Отправить изменения» → «Поделиться файлом»).
5. Диспетчер загружает файлы от всех бригад (меню → «Загрузить изменения от бригад», можно несколько сразу).
6. Вечером диспетчер снова выгружает файл карты и рассылает его — у всех актуальная карта.

Повторная загрузка одного и того же файла ничего не портит. Если две бригады поменяли одно и то же,
остаётся правка, сделанная позже. Перед каждой загрузкой изменений программа делает копию базы.

## Что в папке

| Что | Зачем |
|---|---|
| `Карта сети.bat` | запуск программы (открывается отдельным окном) |
| `Карта сети - ДЕМО.bat` | пробный запуск с выдуманной сетью (отдельная база) |
| `GitHub - подключить и обновить.bat` | связать папку с репозиторием и получать обновления |
| `apk/karta-seti.apk` | приложение для телефона |
| `run.py`, `core/` | программа (Python, без дополнительных пакетов) |
| `web/` | интерфейс: он же вшит в приложение для телефона |
| `android/` | оболочка приложения для телефона |
| `data/` | база, настройки, журнал и резервные копии этого компьютера (в GitHub не попадает) |

## Запуск на компьютере

Нужен Python 3.8 или новее. Запустите `Карта сети.bat`: откроется окно программы. Чёрное окно
закрывать нельзя — пока оно открыто, программа работает. Подпись правок диспетчера и название
меняются в `data\config.json` (поля `operator` и `title`).

## Телефон

Установите `apk\karta-seti.apk` (новую версию — поверх старой, данные сохранятся). При первом
запуске приложение спросит, как подписывать изменения (бригада, фамилия).

## Работа с картой

- **Узел:** «+» → «Узел», подвиньте карту под перекрестие → «Здесь».
- **Линия:** «+» → «Линия между узлами», нажмите на первый узел и ведите линию по точкам («Точка»),
  на конечном узле — «Завершить».
- **Нажатие на узел или линию** открывает карточку, масштаб карты не меняется.
- **Изменить трассу:** в карточке линии. Зажмите линию в любом месте и потяните — появится точка
  изгиба. Точки перетаскиваются; нажатие на точку выбирает её, кнопка «Убрать точку» удаляет.
  «Назад» отменяет последнее действие.
- **Поворот карты** двумя пальцами (на компьютере — правой кнопкой мыши), компас возвращает север.
- Схема или спутник — кнопка со слоями. Карту района можно заранее сохранить на телефон
  (меню → «Карта без интернета»).

## Резервные копии

`data\backups`: раз в сутки и перед каждой загрузкой изменений. Чтобы перенести программу на другой
компьютер, скопируйте папку целиком вместе с `data`.
