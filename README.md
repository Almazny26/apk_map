# Карта сети

Карта узлов и линий транспортной сети связи: приложение для телефона (Android) и программа для
компьютера (Windows). Основа — приложение товарища **«WiFi Френель»** (карта на Leaflet, вшитая
карта и рельеф); с версии 3.0 расчёты радиолиний и паспорт ВОЛС убраны — у линии остаётся
протяжённость.

Прежние версии: 1.3 (своя карта, сервер) — ветка `v1.3-karta-seti`; 2.x — история репозитория.

## Два режима

Сверху — **«Просмотр»** и **«Редактирование»**. При запуске всегда «Просмотр»: ничего нельзя
сдвинуть, нажатие на узел или линию показывает сведения (протяжённость, по опорам / в земле,
откуда и куда, все точки с координатами СК-42).

В «Редактировании»:

- кнопка **«+»** справа внизу — узел, линия ВОЛС, радиолиния;
- точки ставятся **в перекрестие**: двигайте карту и нажимайте «Поставить точку» — или просто
  нажмите на нужное место. Перекрестие на узле зеленеет — линия закончится на нём;
- у линии ВОЛС для каждого участка указывается прокладка: **по опорам** (сплошная оранжевая) или
  **в земле** (коричневый пунктир); одна линия может идти сначала по столбам, потом под землёй.
  Вид точки — опора, колодец, муфта, кросс, точка;
- нажмите на линию — у неё появятся точки: тяните их, «+» между точками добавляет новую;
  узел тоже можно перетащить, концы линий едут за ним;
- **долгое нажатие** (на компьютере — правая кнопка):
  на точку — вид, номер, прокладка соседних участков, удалить;
  на линию — вставить точку здесь, прокладка этого участка, продолжить, название, удалить;
  на узел — изменить, линия ВОЛС или радиолиния отсюда, переместить, удалить.

На телефоне сведения открываются внизу свёрнутыми (название и длина) — нажмите, чтобы развернуть.
Смахивание вниз сворачивает и прячет карточку, но линия остаётся выделенной и её можно править;
выделение снимает «×» или нажатие на пустое место карты.

Кнопка ↶ над кнопками карты (на компьютере ещё Ctrl+Z) отменяет последнее изменение, до 30 шагов.

Справа сверху — поиск и список (🔍) и меню «⋮»: обмен данными, журнал изменений, карта без
интернета, обозначения, инструкция, тёмная тема, настройки.

**Вращение карты.** На телефоне — двумя пальцами, на компьютере — Shift + колесо мыши. Когда карта
повёрнута, справа появляется кнопка-компас: нажатие возвращает север наверх. Вращение можно
выключить в настройках.

## Настройки

«⋮» → «Настройки»: тема (светлая, тёмная, как в системе), размер кнопок и текста, подписи узлов
и линий, размер значков и толщина линий, опоры и колодцы на карте, линейка и кнопки масштаба,
режим при запуске, ставить ли точки нажатием (или только в перекрестие), скорость долгого
нажатия, вибрация, формат координат (СК-42, градусы), на компьютере — ширина панели и строка
координат. Настройки хранятся на устройстве и в файл обмена не попадают; «Сбросить настройки»
возвращает исходные.

## Точки и ответвления

У каждого вида точки линии свой значок: опора — кружок, колодец — квадрат, муфта — ромб, кросс —
квадрат с крестом. Нажатие на значок открывает сведения о точке.

- **Ответвление (Т-образное соединение).** Нажмите на точку линии → «Ответвление отсюда»: точка
  станет муфтой, от неё пойдёт новая линия. Если точки в нужном месте нет — долгое нажатие на линию
  → «Ответвление отсюда (муфта)». Можно и довести новую линию до чужой: перекрестие на линии
  зеленеет, кнопка — «Присоединить к линии (муфта)».
- **Общая опора или колодец.** Точку второй линии можно поставить прямо на значок точки первой.
  Такие точки связаны: перенесёте одну — переедут обе.
- В «Название…» у линии ВОЛС указываются число волокон и марка кабеля.

## Карта без интернета

«⋮» → «Карта без интернета». Район можно **скачать из интернета** (Херсонская область, Запорожская
область, Крым) или **выбрать файл** района (.pmtiles) с устройства. У каждого района два файла:

- **схема** (примерно 80–105 МБ) — рисуется сразу и без связи, на любом масштабе до отдельных домов;
- **снимки** (`<район>-sat.pmtiles`, примерно 110–145 МБ) — съёмка Sentinel-2, 10 м на точку: поля,
  лесополосы, реки, дороги, кварталы. В «Гибриде» поверх них — дороги и подписи схемы.

Выключателя «Карта из интернета» больше нет: есть связь — карта и подробные снимки подгружаются сами,
нет — показывается загруженное. Подробные снимки (отдельные дома, опоры) остаются на устройстве там,
где их уже открывали (до 2 ГБ на телефоне, 4 ГБ на компьютере). Целую область в таком качестве
скачать нельзя: это десятки гигабайт, и владельцы снимков (Esri, Яндекс) массовое скачивание
запрещают.

Источники карт: © участники OpenStreetMap (офлайн-схема — сборка Protomaps), снимки © Esri,
загруженные снимки районов — Sentinel-2 cloudless, https://s2maps.eu, EOX IT Services GmbH (содержит
изменённые данные Copernicus Sentinel 2016–2017, CC BY 4.0), подписи на снимках © Яндекс.

## Обмен файлами

При первом запуске программа спрашивает имя или номер мобильного расчёта — так подписываются
изменения и называется файл.

1. «⋮» → «Обмен данными» → «Поделиться файлом» (телефон) или «Сохранить в файл».
2. Файл называется, например, `Иванов_13.11.26_19.44.json` или `Моб.Расчет№2_13.11.26_19.44.json`
   (время через точку: двоеточие в именах файлов не допускается).
3. На другом устройстве: «Обмен данными» → «Открыть файл…», или на телефоне нажать на файл в
   мессенджере → «Открыть с помощью» → «Карта сети».
4. Программа покажет отличия файла от вашей карты и спросит:
   - **«Добавить новое»** — добавится то, чего у вас нет, обновится то, что в файле правили позже;
     ваше не удаляется;
   - **«Заменить всю карту»** — карта станет точно как в файле.
   Прежняя карта сохраняется: «Обмен данными» → «Вернуть карту, какой она была».

## Что в папке

| Что | Зачем |
|---|---|
| `Карта сети.bat` | запуск программы на компьютере (отдельное окно) |
| `GitHub - подключить и обновить.bat` | связать папку с репозиторием и получать обновления |
| `apk/karta-seti.apk` | приложение для телефона |
| `run.py` | программа для компьютера (Python 3.8+, без дополнительных пакетов) |
| `map/` | файлы офлайн-карты районов (в GitHub не лежат — большие) |
| `web/` | страница приложения: `index.html` (товарища), `app.js` (интерфейс и карта сети), `maps.js` (подложки), `pc.js` (компьютер), `vendor/` (MapLibre GL, leaflet-rotate, шрифты и стиль офлайн-карты) |
| `web/tiles.zip` | общая карта без интернета до масштаба 11 (в GitHub лежит папкой `web/tiles`) |
| `android/` | оболочка приложения для телефона |
| `data/` | данные этого компьютера и резервные копии (в GitHub не попадает) |

## Компьютер

Нужен Python 3.8 или новее. Запустите `Карта сети.bat` — откроется окно программы. Сведения и
меню — в панели слева, справа внизу — масштаб, «вся сеть», «где я», внизу — координаты и СК-42
под курсором. Чёрное окно не закрывайте, пока работаете. Программа доступна только с этого
компьютера, по сети к ней подключиться нельзя. Данные — в `data\state.json`, копия за каждый
день — в `data\backups` (хранятся 30 последних).

## Телефон

Установите `apk\karta-seti.apk`. Новая версия ставится поверх старой, данные сохраняются.

## Для разработки

- Проверка: `python -m unittest discover -s tests -v`.
- Файл района без окна: `python run.py --offline-map crimea --map-file map/crimea.pmtiles`
  (снимки: `--offline-sat crimea --map-file map/crimea-sat.pmtiles`).
- Стиль офлайн-карты: `python tools/offline_style.py web/vendor`.
- APK собирает GitHub Actions при изменениях в `web/` или `android/`.
- Подробности и история решений — в `CLAUDE.md`.

## Чужой код

Leaflet (BSD-2), MapLibre GL JS (BSD-3), шрифты Noto Sans (OFL), **leaflet-rotate** (вращение карты,
GPL-3.0 — поэтому исходный код программы открыт, он весь в этом репозитории). Тексты лицензий — в
`web/vendor/` и `web/leaflet/`.
