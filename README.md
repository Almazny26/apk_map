# Карта сети

Карта узлов доступа транспортной сети и линий между ними для нескольких бригад. Сервер работает на
обычном компьютере с Windows, пользователи подключаются с телефонов (приложение для Android) и из
браузера. Всё, что один человек изменил на карте, у остальных появляется сразу. Без связи приложение
продолжает работать: карта и узлы хранятся на телефоне, правки отправляются, когда связь появится.

## Что в папке

| Что | Зачем |
|---|---|
| `Карта сети - сервер.bat` | запуск сервера |
| `Карта сети - ДЕМО.bat` | пробный запуск с выдуманной сетью (отдельная база, порт 8791) |
| `Открыть доступ по сети (брандмауэр).bat` | разрешить подключения к серверу в брандмауэре Windows |
| `Автозапуск при входе в Windows.bat` | включить или отключить автозапуск сервера |
| `GitHub - подключить и обновить.bat` | связать папку с репозиторием и получать обновления |
| `apk/karta-seti.apk` | приложение для Android (появляется после сборки) |
| `run.py`, `core/` | сервер (Python, без дополнительных пакетов) |
| `web/` | клиент: карта для браузера, он же вшит в приложение |
| `android/` | оболочка Android-приложения |
| `data/` | база, настройки, журнал и резервные копии этого компьютера (в GitHub не попадает) |

## Запуск сервера

1. Нужен Python 3.8 или новее. Больше ничего устанавливать не требуется.
2. Запустите `Карта сети - сервер.bat`. В окне появятся адреса, по которым сервер доступен.
3. При первом запуске создаётся администратор. Его логин и пароль записаны в файле
   `data\ПЕРВЫЙ ВХОД.txt` и показаны в окне сервера.
4. Откройте в браузере `http://localhost:8790`, войдите как `admin`, смените пароль
   (меню → «Настройки и учётная запись») и заведите учётные записи сотрудникам (меню → «Пользователи»).

Порт и название можно поменять в `data\config.json` (создаётся при первом запуске).

### Права пользователей

- **Администратор** — всё, плюс пользователи и справочники (виды узлов, виды линий, состояния).
- **Редактор** — добавляет, меняет и удаляет узлы и линии.
- **Только просмотр** — видит карту и журнал, ничего не меняет.

## Доступ из интернета

Телефоны ходят к серверу через мобильный интернет, поэтому сервер должен быть виден снаружи.

1. Запустите `Открыть доступ по сети (брандмауэр).bat`.
2. На роутере пробросьте TCP-порт 8790 на адрес компьютера с сервером. Нужен белый (публичный)
   статический IP-адрес от провайдера.
3. Адрес для телефонов: `http://ВАШ_ВНЕШНИЙ_АДРЕС:8790`.

**Про безопасность.** Без HTTPS логины, пароли и данные идут по сети открытым текстом. Сервер умеет
HTTPS сам: получите сертификат на своё доменное имя и укажите пути к файлам в `data\config.json`
(`https_cert` и `https_key`), после чего адрес станет `https://ваш-домен:8790`. Самоподписанный
сертификат не подойдёт: приложение и браузеры ему не доверяют. От подбора пароля сервер защищается
сам: после пяти неудачных попыток входа адрес блокируется на минуту, дальше дольше.

## Приложение для Android

1. На телефоне откройте в браузере адрес сервера. На странице входа есть ссылка «Скачать приложение
   для Android». Прямая ссылка: `http://АДРЕС:8790/apk/karta-seti.apk`.
2. Установите скачанный файл (телефон попросит разрешить установку из этого источника).
3. В приложении укажите адрес сервера, логин и пароль. Вход запоминается.

Когда на сервере появляется более новая версия, приложение сообщает об этом, обновление
скачивается из меню → «Настройки и учётная запись».

## Работа с картой

- **Добавить узел:** «+» → «Узел», подвиньте карту так, чтобы перекрестие встало на нужное место
  (кнопка «Моё место» ставит перекрестие туда, где вы стоите) → «Здесь» → заполните карточку.
  Координаты можно ввести и вручную.
- **Провести линию:** «+» → «Линия между узлами», нажмите на первый узел (или в карточке узла —
  «Линия отсюда»). Дальше ведите линию по точкам: наведите перекрестие на поворот улицы и нажмите
  «Точка», и так до конечного узла. Когда перекрестие встанет на узел, кнопка сменится на
  «Завершить». «Назад» убирает последнюю точку. Точку можно поставить и простым нажатием на карту,
  а завершить линию — нажатием на конечный узел.
- **Поправить трассу:** в карточке линии — «Трасса». Точки изгиба можно тянуть пальцем. Бледная
  точка посередине каждого отрезка добавляет новый изгиб, если её потянуть. Нажатие на точку
  убирает её, «Назад» отменяет последнее действие, «Спрямить» убирает все изгибы.
- **Состояние** узла или линии меняется одной кнопкой прямо в карточке.
- **Переместить узел:** в карточке — «Переместить».
- **Поиск** по названию и адресу — в строке сверху. Меню → «Узлы и линии» — полный список.
- **Обозначения и фильтр:** форма значка — вид узла, цвет — состояние. Линия окрашена по виду,
  состояние, отличное от обычного, подсвечивает её.
- **Журнал изменений:** кто, когда и что поменял. В карточке объекта — «История».
- **Схема или спутник** — кнопка со слоями справа.

### Без связи

Индикатор справа вверху показывает состояние: «В сети», «Отправка» или «Нет связи» и число
неотправленных правок. Без связи можно смотреть карту и вносить правки, они отправятся сами. Если
двое без связи поменяли разные поля одного узла, сохранятся обе правки. Если одно и то же поле —
останется та, что дошла до сервера последней, обе записываются в журнал.

Карта, которую уже просматривали, сохраняется на телефоне. Чтобы заранее сохранить целый район:
меню → «Карта без интернета».

## Импорт и экспорт

В браузере: меню → «Импорт и экспорт». Узлы выгружаются в CSV (открывается в Excel), вся сеть — в
GeoJSON. Узлы можно загрузить из CSV со столбцами «Название», «Широта», «Долгота» и по желанию
«Вид», «Состояние», «Адрес», «Примечание».

## Резервные копии и перенос

Сервер раз в сутки сохраняет копию базы в `data\backups` и хранит 14 последних. Чтобы перенести
сервер на другой компьютер, скопируйте туда всю папку целиком вместе с `data`.

## Обновление

Исходный код хранится в репозитории GitHub `Almazny26/apk_map`. `GitHub - подключить и
обновить.bat` связывает папку с репозиторием и забирает свежую версию. Папка `data` при этом не
затрагивается. После обновления перезапустите сервер.
